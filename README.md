# SpellLab · 单词句子拼写记忆

一个**单文件、离线可用**的英语拼写练习网页应用。打开 `SpellLab.html` 即可使用，无需安装、无需联网、无需后端；所有学习数据保存在浏览器内置的 **IndexedDB 本地数据库**中，`localStorage` 作为兼容镜像与降级通道。

同一份 `SpellLab.html` 也可以作为 **Python 桌面程序**运行：`desktop/app.py` 用标准库起本地服务 + 真实 SQLite 数据库文件，并用独立应用窗口呈现，零第三方依赖。详见 [desktop/README.md](desktop/README.md)。

源自一张练习软件截图：看中文句子，按逐词中文提示把英文句子拼出来。在此基础上补齐了分步记忆、单词速记和一套教学/生词管理功能。

## 功能

- **句子拼写**：中文题干 + 逐词中文提示，把英文句子拼出来；每个单词默认按字母数显示一排**小空格**，整句横向排列、一行放不下自动换行，输满自动判定。「练习设置」里可关闭小空格回到整词输入框，也可配置「预先露出字母」0–3 个（露出的字母是提示，不用再输入）；支持空格/回车提交、Tab 与方向键切词、两级提示、错词标红抖动、英文朗读。
- **分步记忆**：认短语 → 逐块拼写 → 整句拼合。整句拆成 2–3 个短语卡片，先认后练，最后独立完成整句。
- **单词速记**：打乱的字母块拼写单词，支持键盘直接输入、退格删除、答对自动发音。
- **打字练习 🦆**（第四个主模式）：帮助孩子熟悉键盘键位的打字小游戏，含 8 种玩法——认识字母（跟着高亮认键位）、字母连打（限时冲量）、单词练习、拼音练习、打地鼠、错键专项（自动统计常按错的键针对性练）、听音打字（听英文发音打单词）、亲子 PK（两人轮流比拼）。带可视化虚拟键盘，按键按「该用哪根手指」着色，目标键发光并提示「用左手食指按 F 键」；无压力纠错，按错只需重试。还有每日打卡、小鸭养成（星星喂食升级）、8 枚成就勋章、4 关键位闯关地图、盲打挑战（藏起按键字母）和 4 种主题皮肤。**每局结束按星级结算 SpellLab 积分**（1★=2 分，最高 6 分），计入积分流水，可拿去转盘抽奖。该模式是独立浅色游戏区，不影响其余深色的拼写模式。
- **成长中心 🚀**（第四个主模式旁的新入口，顶栏「成长中心」与侧栏「成长」均可进入）：四个面向记忆巩固的工具，全部使用独立的 `state.memo` 命名空间，兼容旧存档并随全库备份一起保存。
  - **错词复习（艾宾浩斯遗忘曲线）**：句子拼错、单词拼错或用提示时自动收录出错的词句；答对按 **1→2→4→7→15→30 天**逐级推远到期日并提升等级（L0–L6），答错则归零、当天重练。首页显示「今日待复习 / 收录词句 / 已进入长期记忆」，可「开始今日复习」或「复习全部」，也可清空计划（不影响主进度和生词本）。复习采用中文提示 → 输入英文 → 即时判分，一次答对计入积分与练习记录。
  - **听写练习 🎧**：只播放英文发音、隐藏文字，凭听觉写出单词或句子（当前单元内容，每轮最多 12 题）。支持反复重听、跳过、显示答案；连对归零规则与历史最佳连对写入存档，成绩同样计入积分和复习计划。
  - **单词闯关地图 🗺️**：每个单元是一关，按该关词句的掌握度自动评 1–3 星；默认点亮一关解锁下一关，也可一键开启「自由闯关」任意跳关。点击关卡直接跳到对应单元的句子拼写。
  - **学习统计 📊**：累计练习、一次答对率、连续练习天数、掌握词句、累计积分五项指标卡；近 7 天练习题数 / 一次答对数双色柱状图；各模式练习分布条形图。数据全部来自本机练习记录，不联网。
- **自然拼读 🔤**（顶栏主模式，与「句子拼写 / 单词速记」并列）：点顶栏「自然拼读」直接进入主练习区，不用再开侧栏；侧栏「拼读」页保留一个跳转入口。两种来源。**内置课程**：5 组 56 课 230 个代表词（字母音 → 短元音 → 长元音 → 辅音组合 → 常见词族），无需联网或额外教材。**教材单词**：直接练已导入课本的词表，**教材范围直接复用顶部「学习范围」**（学制 / 学段 / 年级 / 教材 / 册别），拼读里不再单独配一套——顶部一改，这里的词库即时同步；可按单元练，也可切到「按拼读规律」把 sh / ee / a_e / 短元音等自动跨单元归类；词组与带撇号、连字符的词不参与音节拆分。**拼读块按主流音节规则切**，每个音节一个元音核心：VC/CV 两辅音中间切（ap-ple）、V/CV 先试前切长音（ti-ger）、常见短元音闭音节词按 VC/V 后切短音（cab-in / sev-en）、C+le 词尾自成节（ta-ble / pur-ple）、V/V 双元音各自成节（li-on / di-et）、常见前后缀在词缀边界切（re-play / jump-ing / hope-ful），digraph（sh/ch/th/ck 等一音二字母）不拆，st/bl/tr 这类辅音连缀要拆（res·tau·rant），词尾 C+le 除外、神奇 e 与元音同节（cake）；au/aw/ue/eau 等二合元音整体成节（be·cause / beau·ti·ful），ready/real/restaurant 的 re 属词根不当前缀。例如 apple → ap·ple、banana → ba·na·na、computer → com·pu·ter、cabin → cab·in、replay → re·play、restaurant → res·tau·rant。**易错词优先查词典校订表**：Merriam-Webster / Cambridge 的点分音节是人工校订依据，LibreOffice/Pyphen 连字符词典提供批量候选，`textbooks/phonics-syllables.json` 保留全部 2346 个教材词的 `en_US/en_GB` 参考拆分；断行 hyphenation 只作参考，不直接当教学音节。现在 gingerbread → **gin·ger·bread**、readable → read·able、family → fam·i·ly、dictionary → dic·tion·ary，`kilometre → ki·lo·me·tre`、美式 `kilometer → ki·lo·me·ter`（仅尾节 tre/ter 随英美拼写不同，`metre/meter`、`millimetre/millimeter` 同理），bread/ready/tiger/me 的提示音也一并修正。**答题界面和句子练习完全同款**：一张大练习卡片、中文题干大字、按音节分成输入格（点字母格逐段输入、输满自动判定、空格/回车确认、Tab 跳到下一个音节、每格下方显示音素提示），全部拼对弹出成功卡片，可朗读单词 / 下一题。选课时才显示课程列表，答题时收起。每词两种练法：**听音拼词**（只听发音 + 看中文，先给音节空格，点「拼读提示」再看字母组合和读音）与**看词拼读**（看中文 + 音节读音提示拼出英文），可反复重听、看答案、换一题；答对计入拼读进度（1–3 星）、练习记录与打卡日历。内置课程与教材单词的进度分别存 `state.phonics.done` 和 `state.phonics.textbookDone`，随全库备份保存、兼容旧存档。
- **音效与朗读**：Web Audio 实时合成，无任何音频文件依赖。按键音、删除音、正确/错误音、整题完成音、卡片翻面音；可静音与调音量。**整句拼完后默认自动朗读完整英文句子**，延迟默认 120ms（可在「练习设置」0–600ms 调整或关闭），成功卡片也能重听。
- **词间距、长提示与自动换行**：单词之间默认留 22px（设置里 10–44px 可调）；逐词中文提示改在各单词**正下方**参与布局，中文再长也只在本词范围内换行。整句按每个单词的**真实宽度**自动换行，短词整词一起换行；特别长的单词（10 个字母以上）只在自己这一格内折行，不会再溢出盖住相邻单词，长中文题干也会自动折行。
- **练习计时与难度**：题干下方显示已用时间或倒计时，可在「只显示用时 / 倒计时」间切换；简单 120 秒 / 两级提示 / 多露 1 个字母，正常 60 秒 / 两级提示，困难 35 秒 / 只有首字母提示。倒计时到点自动显示整句答案并记为「借助提示」。
- **年级 / 教材版本管理**：顶部按「学制 → 学段 → 年级 → 教材 → 册别」级联筛选学习范围。六三制为小学 1–6 年级 / 初中 7–9 年级，五四制为小学 1–5 年级 / 初中 6–9 年级；选小学就只出现小学教材和年级，选初中同理。管理页可增删改名，并为每个单元单独设置归属。
- **生词本**：手动录入（大小写去重）、搜索、只看未掌握、标记掌握、朗读、移除；支持导入当前单元单词、从错题取词、单词速记一键收藏。**拼错、用提示或单词拼错时自动加入生词本**（默认开，可在练习设置关闭），句子工具条与成功卡片也有「本题生词入本」。
- **从生词本创建练习**：勾选生词生成听写题 + 例句填空题，保存为独立课程单元，三种模式都能练。
- **单元一轮完成提示**：一个单元的所有题目练完一轮后弹框，可选「进入下一单元」「继续本单元」「稍后再说」。
- **断点续练**：退出时保存当前模式、单元、题序和未填完的字母；下次启动询问「继续上次练习 / 重新开始」。可在练习设置关闭询问。
- **学习计划与积分**：「计划」页可按当天练过的不同单元数或累计练习分钟数定每日目标，达标加分、未达标扣分（每天首次打开自动结算前一天）；一次答对（含自然拼读，每答对一题即发、不用等整课做完）也可加分，积分最低为 0。
- **幸运转盘**：抽奖入口已从侧栏挪到页面右上角（积分旁边），点「转盘抽奖」打开带金色灯环、糖果色扇区细分隔线和中心「抽奖」圆钮的转盘；扇区按中奖概率分配，剩余概率为「谢谢参与」，转到哪个扇区就得哪个奖项，中奖后弹出结果卡片，每次消耗积分并写入「抽奖」页记录。转盘下方是带色块的完整奖项图例，奖项名太长时盘面只显示短名、过窄的扇区不画文字，避免挤成一团；侧栏只保留积分 / 奖项查看与最近记录。扇区颜色、盘面标签、12 点指针与抽奖结果统一以 `conic-gradient(from 0deg)` 的 0°＝正上方为基准（曾误用 `from -90deg`，会让整盘扇区相对标签和指针错开 90°）；抽奖直接按盘面扇区抽取，结果卡片的色点与图例高亮行就是指针停下的那一区。
- **兑换状态与自动兑换**：「抽奖」页新增「获得的奖品」列表，逐条显示奖品、时间与状态。添加 / 编辑奖项时可勾「自动兑换」（如默认的「再抽一次」）：**抽到即自动生效，本次不扣积分**，结果卡片标「自动兑换 · 不扣分」。未勾选的奖项抽到后扣积分并标「待兑换」，孩子能看到自己的奖品，但要家长在列表里点「标记已兑换」才会变成「已兑换」；待兑换数量在标题徽标上实时显示。旧存档的历史抽奖记录默认按已兑换处理，不会突然冒出一堆待兑换。
- **奖项编辑即时生效**：改名称、概率、增删奖项或每次消耗积分后，侧栏与已打开的转盘一起刷新并复位圆盘角度，不会再出现「扇区已重画但盘面还停在上次落点、指针指错奖项」。所有奖项概率合计自动限制在 100% 以内（超出会自动截断并提示），旧存档与全库备份里超过 100% 的概率加载时也会收敛；概率为 0% 的奖项不占扇区，但会灰显保留在图例里。若概率仍异常，转盘会显示警告并禁用抽奖。
- **家长中心与管理密码**：右上角「家长」入口，**初始管理密码 `1234`**，解锁后可修改奖项内容、中奖概率、每次消耗积分，并可修改管理密码或立即锁定。未解锁时奖项只展示不可编辑，孩子仍可自由练习和抽奖。保护范围做成可配置的 `PARENT_SCOPES` 注册表，以后要保护练习设置、学习计划等只需注册新域并给控件包一层 `guardParent()`。密码只存 `salt + 哈希`，不存明文；刷新或重启程序后家长模式自动重新锁定。
- **学习系统**：3 个内置单元共 22 句 + 43 张单词卡、错题本、掌握度驱动的智能复习、连对/正确率/今日完成统计。
- **练习记录与最快用时**：侧栏「记录」页逐条保存每次练习的时间、模式、单元、句子、是否借助提示、用时与错误次数；按天分组查看，可导出 CSV、单独清空。最多保留最近 500 条，随全库备份与 SQLite 一起保存。升级前的累计答题数仍保留在「学习」统计里。所有答题型练习（整句 / 分步 / 单词 / 拼读 / 错词复习 / 听写 / 纸笔听写 / 打字）都统一统计完成用时；**每个词句单独记个人最快**，只认一次答对、未借助提示、用时在 0.3 秒～30 分钟之间的成绩。打破纪录时弹出「⚡ 速度突破」鼓励动画（本次 / 原纪录 / 快了多少 + 彩带），不拦截输入、2.6 秒自动收起；首次完成只静默建立纪录。记录页新增「个人最快」榜（前 10 名）与「速度纪录 / 今日最快」统计格，破纪录的条目带 ⚡ 标记。打字小鸭按「平均每次答对用时」计入（局时长固定，直接记局用时会没有突破意义）。
- **教材库（本地教材包）**：按「小学 / 初中 → 教材类别 → 年级(上/下) → 单元 → 句子 / 单词表」分层显示，教材库面板顶部的学段选择与顶部学习范围联动，册包按年级、上/下册排序；支持多套教材并存、单元增删改名、单题增删改、手动短语拆分、批量粘贴题目与单词表、启停教材包；教材包可导出为 JSON 提交到 Git 管版本或分享，另有全库备份 / 恢复。
- **自定义题库**：按 `中文句子 | 英文句子 | 提示1,提示2,...` 每行一题导入，提示数需与英文单词数一致；未写短语拆分时自动均分。
- **本地数据库**：IndexedDB 事务型存储（容量按磁盘剩余空间分配）、旧存档自动迁移、用量与持久化授权管理、绑定本地 JSON 文件自动写回、导出 SQLite `.sql`、跨标签页同步。

## 使用

双击 `SpellLab.html`，或直接用浏览器打开该文件。

首次点击或按键后音效才会激活（浏览器自动播放策略）；朗读使用浏览器内置英文语音引擎，需要系统装有英文语音包。

建议上手路径：管理页把年级/教材调成自己用的版本 → 教材库里建教材包与单元、录入课本句子 → 顶部筛选学习范围 → 生词本里导入当前单元单词或手动加词 → 勾选后生成练习集开练。数据要长期保存或换设备时，到「存储」页绑定一个本地 JSON 文件（或导出全库备份）。

## 桌面版（Python，可选）

```bash
cd desktop
python app.py          # Windows 也可双击 run.bat
```

零第三方依赖：Python 标准库 `http.server` + `sqlite3` 提供本地服务与数据库，Edge/Chrome 的 `--app` 参数提供无地址栏的独立窗口；装了 `pywebview` 时加 `--pywebview` 可换原生 WebView 窗口。

数据落在 `desktop/dist/data/spelllab.db`，是普通 SQLite 文件，含 `state`（全量快照）与 `grades` / `books` / `packs` / `units` / `questions` / `words` / `vocab` / `progress` / `wrong` / `stats` / `history` 等规范表，可直接用 SQLite 工具查询。**双击 `run.bat`、双击 `SpellLab.exe`、IDEA 运行配置三者共用同一个数据库文件**（`run.bat` 与运行配置都设置了 `SPELLLAB_DB` 环境变量），不会「换个入口打开，之前的练习全没了」。网页版导出的全库备份放进 `data/` 会在首次启动时自动导入。打包成 exe 后数据库在 exe 同目录的 `data/`，不会写进打包程序的临时解压目录。

每次答对/答错、收藏生词、改动设置等**关键操作立即写盘**，普通改动 60ms 内合并写入；直接关窗口时页面会用 `sendBeacon` 补写最后一次状态，服务端延迟 1.2 秒退出等它落库。侧栏顶部显示当前数据库位置与保存状态（`已保存 HH:MM` / `正在写入…` / `写入异常`）。注意：**网页版（直接双击 HTML）用浏览器 IndexedDB，与桌面版 SQLite 是两套独立数据**，需要互通时用「导出全库备份 → 导入备份」。

完整说明、参数、打包 exe 与迁移步骤见 [desktop/README.md](desktop/README.md)。

用 PyCharm / IntelliJ IDEA 开发时，项目已配成 Python 项目（项目内 `.venv`、模块与测试根、运行配置），环境限制与两条使用路径见 [IDEA_SETUP.md](IDEA_SETUP.md)。

## 教材包管理

层级是 `教材包（一册书） → 单元 → 句子 + 单词表`。每个含题目的单元会自动成为课程单元，进入句子拼写 / 分步记忆 / 单词速记三种模式，并参与顶部年级 / 教材筛选。顶部的「打字练习」是独立的键位训练游戏，「成长中心」则提供错词复习、听写、闯关地图和学习统计四个巩固工具，二者都不依赖教材数据，任何状态下都能点开。

- **新建**：学习面板 →「教材库」→ 填名称、选年级与教材版本 → 创建 → 加单元。
- **录题**：点单元名打开编辑器。单题需填中文、英文、逐词中文提示（数量必须等于英文单词数）；短语拆分可留空（自动均分），格式为 `短语中文:词数,...`，词数之和须等于单词数。也可批量粘贴多行题目或 `英文,中文` 单词表。
- **导出**：单包「导出此包」或「导出全部教材包」生成 `.json`，内容同时填入页面文本框方便复制。
- **导入**：粘贴 JSON 或选择 `.json` 文件；包与单元会重新生成 id 避免冲突；JSON 带 `gradeName` / `bookName` 时，本机缺失的年级 / 教材版本会自动补建。
- **备份**：「导出全库备份」包含进度、错题、生词、设置与全部教材；「从备份恢复」覆盖当前全部数据，操作前请先备份。

## 预制教材包：人教版 PEP（三年级起点）

仓库的 [`textbooks/`](textbooks/README.md) 已备好可直接导入的教材包，覆盖三上~六下 8 册 / 46 单元 / 849 词 / 254 句：

- `textbooks/pep-sanqi-2024.json`：总包，一次导入 8 册。
- `textbooks/packs/pep-3a.json` … `pep-6b.json`：按册拆分，按需导入单册。

三上~六上为 2024 新课标版（2024 秋–2026 秋滚动启用），五下、六下仍是现行 2013 审定版（2027 春换新版）。在「教材库」导入区选择 `.json` 文件即可；版本对照、内容准确性说明与重新生成方法见 [textbooks/README.md](textbooks/README.md)。


## 本地数据库与数据存放

应用仍是单文件，但数据不再只塞在 `localStorage` 里：

| 层 | 用途 | 说明 |
|---|---|---|
| **IndexedDB**（主库） | 全部学习数据的权威副本 | 数据库 `spelllab.db` / store `kv` / 键 `main`，事务写入，容量通常按磁盘剩余空间分配；`fileHandle` 键保存绑定的文件句柄 |
| **localStorage 镜像** | 启动快照 + 兼容旧版 | 键 `spelllab.state.v1`（旧格式，保持兼容）、`spelllab.savedAt.v2`（时间戳）；超过配额会自动停用，只留主库 |
| **本地数据文件**（可选） | 可见、可迁移、可进 Git | 绑定一个 `.json` 后自动写回，内容等同全库备份 |

启动时比较主库与镜像的 `savedAt`，取较新的一份；旧版存档首次打开会自动迁入 IndexedDB。隐私模式或不支持 IndexedDB 的环境自动降级为 localStorage，界面会明确标注。

打开「学习面板 → 存储」或顶部「本地数据库」可以看到：引擎状态、站点用量 / 配额、教材包 / 题目 / 生词 / 错题 / 进度记录数、最近保存时间、持久化存储授权、迁移状态、镜像状态；并能申请持久化授权、立即写库、绑定 / 解除本地文件、导出备份或 SQLite 脚本、从备份恢复、清空数据库。

### 生成真正的 SQLite 数据库文件

存储页点「导出 SQLite .sql」，然后在本机执行：

```bash
sqlite3 spelllab.db < spelllab-2026-11-15.sql
```

得到 `spelllab.db`，可用任意 SQLite 工具查询。脚本含 `grades` / `books` / `packs` / `units` / `questions` / `words` / `vocab` / `progress` / `wrong` / `stats` / `history` / `plan_ledger` / `prizes` / `lottery_log` / `app_meta` 共 15 张表；`hints`、`chunks` 以及计划 / 奖项 / 练习现场 / 家长密码哈希的完整配置以 JSON 文本保存（`app_meta` 现含 4 份 JSON）。这是**导出快照**，应用运行时不依赖 SQLite。

### 仍需注意

- 数据只在这台设备的这个浏览器里，不联网、不跨设备自动同步；换设备靠导出的 JSON 文件或绑定的本地文件。
- 绑定的本地文件自动写回需要 Chrome / Edge 的 File System Access API，并由用户点击授权；刷新页面后需再点一次「立即同步」恢复授权。Safari / Firefox 可用手动导出的备份文件。
- 多个标签页同时打开时，较新的写入会同步到其他标签；仍建议只在一个标签里编辑教材，避免相互覆盖。
- 清理浏览器站点数据、卸载浏览器会删除 IndexedDB，重要教材请导出 JSON 提交到 Git 或放进网盘。
- **家长密码不是加密级安全**：它的作用是防止孩子随手改抽奖设置，密码哈希与 salt 都存在本机状态里，能直接编辑数据文件的人仍可绕过。请勿用它保护敏感信息，首次解锁后请尽快把初始密码 `1234` 改掉（改过后界面不再显示初始密码提示）。

教材包 JSON 只含教材内容，与学习进度互不影响，因此适合提交到 Git 做内容版本管理或分享给他人导入；跨设备同步进度则通过全库备份文件。

## 练习显示：字母格与自动换行

句子拼写、分步记忆的整句阶段、从生词本生成的练习共用同一块拼写板。默认开启「按字母显示小空格」：每个单词渲染与字母数相同的小格，整句横向排列，词槽按内容真实宽度参与换行，一行放不下时整个单词一起换行。**如果一个单词比一整行还宽**（例如 `internationalization`），字母格只在这个词槽内部折成两行，不会溢出到相邻单词上；此时答案区高度会自动增高，词间距与中文提示仍按整词对齐。当前待输入的格子高亮，逐字输入时字母依次填入，输满自动判定。

学习面板 →「练习设置」里的相关设置：

| 设置 | 说明 |
|---|---|
| 按字母显示小空格 | 关闭后回到原来的「一个词一条横线」整词输入框 |
| 预先露出字母 0–3 个 | 前 N 个格子直接显示真实字母作为提示，只需补输入剩下部分；短词自动少露一些，至少留一个字母给用户 |

改动后当前题会重做；设置随全库备份 / SQLite 一起保存，旧存档导入时会自动补上默认值。

## 验证脚本

全部是本地脚本，不联网、不改动学习数据：

```bash
node tests/runtime.cjs     # 84 项：存储、教材库、备份、桌面桥接，以及成长中心的
                           #        错词间隔复习、听写、闯关星级、学习统计等运行时逻辑
node tests/board.cjs       # 15 项：字母格渲染、露出字母、输入判定、整词模式回退、长词折行
node tests/features.cjs    # 91 项：自动朗读延迟、练习记录、用时统计与个人最快、落盘/beacon、间距与难度计时、
                           #        生词自动收藏、断点续练、单元完成提示、积分计划与转盘、
                           #        家长密码哈希 / 解锁 / 改密 / 保护域 / 奖项锁定、
                           #        转盘视觉、改奖项后角度复位、概率收敛、0% 奖项与短标签、
                           #        扇区/标签/指针角度基准、结果与分区颜色及落点一致、
                           #        词典校订音节表（gingerbread→gin·ger·bread 等）、自然拼读积分、听音打字字母大小写
node textbooks/verify.cjs  # 16 个教材包用应用真实导入函数解析
python -m unittest discover -s desktop/tests   # 25 项 Python 单测（Windows 用 .venv\Scripts\python.exe）

# 可选：重新生成拼读音节参考数据（仅开发时需要）
.venv\Scripts\python.exe -m pip install pyphen
.venv\Scripts\python.exe textbooks/build_phonics_data.py
```

## 技术

原生 HTML + CSS + JavaScript，单文件零依赖。音效由 Web Audio API 合成，题目数据内嵌在文件中；存储使用 IndexedDB + File System Access API + Storage API，全部带能力检测与降级。
