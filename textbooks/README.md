# SpellLab 预制教材包（小学 + 初中）

这里是 SpellLab 可直接导入的 `spelllab.textbook.v1` 教材包。

## 小学：人教版 PEP（三年级起点）

覆盖小学三年级到六年级共 8 册、46 个单元、**886 个单词 / 278 个句子 / 1311 条逐词中文提示**。

- `pep-sanqi-2024.json` —— 总包，一次导入全部 8 册。
- `packs/pep-3a.json` … `packs/pep-6b.json` —— 按册拆分，只学某一册时导入对应文件即可。

## 初中：人教版《义务教育教科书·英语》（2024 修订版）

官方书名是《义务教育教科书·英语》（人民教育出版社，刘道义、郑旺全主编），**不是** 2013 年旧版的《新目标 Go for it!》。这套依据 2022 版课标修订，教材封面印「2024」，按年级滚动启用，**2026 年在用的八下、九上都属于这套 2024 修订版**——文件名 `junior-2024.json` 里的「2024」是修订版代号，不是内容年份。

覆盖七上到九下共 6 册、47 个单元（含 3 个 Starter Unit）、**1928 个教材单词 / 236 个练习句**。单词来自各册 `Vocabulary in Each Unit` 的公开转录，清洗后按册去重、只保留应用支持的**单个单词**（词组、缩写、人名地名已剔除）；册名含「上册 / 下册」，导入后会自动归入对应册别（筛选可见）。

- `junior-2024.json` —— 总包，一次导入全部 6 册。
- `packs/pep-7a.json` … `packs/pep-9b.json` —— 按册拆分导入。
- 源数据 `source/pep_junior.json`，构建脚本 `build_junior.py`。

版本判断详见下面的「初中版本对照（2026-11 复核）」与「初中数据的边界」。

## 怎么导入

1. 打开 SpellLab（浏览器直接打开 `SpellLab.html`，或双击桌面版 `run.bat` / `SpellLab.exe`）。
2. 进入「学习面板 / 管理 → 教材库」，在导入区选择 `.json` 文件（或把文件内容粘进文本框），点导入。
3. 导入后在顶部用「年级 / 教材版本」筛选学习范围；每个含句子的单元会自动成为课程单元，可练**整句拼写、分步短语记忆、单词速记**三种模式。
4. 想新建练习，可在生词本里导入当前单元单词，勾选后生成练习集。

导入会给包和单元重新生成 id，所以**重复导入会产生重复教材包**；升级前请先导出备份或在教材库里删掉旧包。教材包 JSON 只含教材内容，不含学习进度，适合提交到 Git 做版本管理。

## 内容构成与准确性说明

以下各条以**小学包**为主；初中包的差异（真实教材词表、句子自编、九下未定稿）见上一节。

- **单元名**：取自人教社官网与电子课本目录，如六上为 `Amazing places / Getting together / Healthy life / Managing money well / Exploring space / Energy, nature and us`，与新版正式目录一致。
- **单词表**：取自各册附录「Words in each unit」及公开的按单元词汇表，带中文释义。应用单词模式只支持**单个单词**，所以 `look after`、`bus stop`、`ice cream`、`get up` 这类词组没有放进单词卡，但会出现在句子里；同一册内重复单词已去重。
- **句子**：按各单元重点句型 / 常用表达整理的短句（3–10 词）并配中文翻译，用来做拼写练习。**不是逐字复制课文对话**，措辞可能与课本原句略有差异，用于预习复习请以手中课本为准。
- **逐词提示 `hints`**：由 `build.py` 依据本套词表 + 功能词词典自动生成，数量严格等于应用 `tokenize()` 切出的单词数，导入时不会被 `validateQuestion()` 丢弃。
- **短语拆分 `chunks`**：留空，应用会在「分步记忆」模式自动均分短语音节；如需按语义手工拆分，可在教材库编辑器里逐题设置。
- 英文句子只含字母、空格和 `' . , ! ? -`，不含阿拉伯数字（数字写成英文单词，如 `six o'clock`），以符合应用的题目格式校验。

资料来源：人民教育出版社官网目录（pep.com.cn）、电子课本网目录（dzkbw.com）、公开的 2024 新版按单元词表与知识点整理（zy.21cnjy.com、wenku.baidu.com、mp.weixin.qq.com、c.sjds.net、yyld.51jiaoxi.com 等）。本套数据仅供个人学习与家庭辅导使用，请以正版教材为最终依据；五下、六下待 2027 春新版发布后建议重新整理。

## 维护 / 重新生成

源数据在 `source/pep_3_4.json`、`source/pep_5_6.json`（小学）与 `source/pep_junior.json`（初中），结构都是「每册 → 单元 → words / sentences」，只改这三份即可，两个构建脚本负责补提示、校验和导出。`source/junior_hints.json` 是初中练习句的中文提示备用词典，改动词表后若出现「句子词无中文提示」的警告，把缺的词补进它即可：

```bash
.venv/Scripts/python.exe textbooks/build.py          # 重新生成小学总包 + 8 个分册
.venv/Scripts/python.exe textbooks/build_junior.py   # 重新生成初中总包 + 6 个分册
node textbooks/verify.cjs                            # 用 SpellLab.html 里的真实导入函数验证全部包
```

`verify.cjs` 会从 `SpellLab.html` 抽出 `validateQuestion` / `tokenize` / `normalizeImportedPack` / `parsePackJSON` 在沙箱里运行，逐项比对导入前后的包、单元、句子、提示与单词数量，确保不会被静默丢弃。若新增句子用到词表里没有的词，构建脚本会打印警告，把该词补进 `build.py` 的 `EXTRA` 词典即可。
