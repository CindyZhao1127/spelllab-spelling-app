本地数据库

检测中…
IndexedDB 是浏览器内置的事务型数据库，容量通常按磁盘剩余空间分配，远大于 localStorage 的约 5 MB。数据仍只保存在本机、不联网；旧版存档会自动迁移。

网盘同步（绑定本地数据文件）

先在坚果云 / OneDrive / 百度网盘的同步目录里建一个 spelllab.json，再点下面的「绑定本地文件」选中它。之后每次学习数据变化都会自动写回，另一台设备打开后点「立即同步」即可恢复授权并读取该文件。需 Chrome / Edge；Safari / Firefox 请用下方「导出全库备份 / 从 JSON 备份恢复」。

百度网盘直连（OAuth）

仅桌面版可用。先在 百度网盘开放平台 完成实名认证并创建「软件 / 个人使用」应用，拿到 AppID、AppKey、SecretKey；在「安全设置」里把回调地址填成 http://127.0.0.1:8791/oauth/callback（填写后约 1 小时生效）。应用名称要和下方的「应用文件夹名」一致，备份只会写进你网盘的 /apps/应用名/SpellLab/ 目录。授权失败且提示回调端口被占用时，先关掉其他旧 SpellLab 窗口再点「授权登录」。

导出与迁移

全库备份含进度、错题、生词、教材与设置。SQLite 导出生成 .sql 脚本，在命令行执行 sqlite3 spelllab.db < spelllab-日期.sql 即可得到可被外部工具查询的数据库文件。

数据库维护

清空数据库会重置本机全部学习数据并回到默认状态，不会删除你绑定的文件。操作前建议先导出备份。

桌面版数据文件

桌面版把全部数据写进一个 SQLite 文件，可用 DB Browser for SQLite、命令行 sqlite3 等工具直接打开查询；备份会自动存到 data/exports/。
从网页版迁移：在网页版顶部「数据 / 网盘同步」→「数据同步」页导出全库备份，把文件放到 data/ 目录并命名为 spelllab-backup.json，桌面版首次启动会自动导入；也可在这里直接选择文件恢复。
